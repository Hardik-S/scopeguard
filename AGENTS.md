# ScopeGuard Worker Rules

This repository contains public synthetic examples only. GitHub owner: Hardik-S.

The Director owns architecture, integration, commits, pushes, issues, and releases. Workers edit only their assigned files, preserve others' changes, and return changed paths, exact tests, failures, and the next action. No new dependencies without Director review.

Read SPEC.md before implementing. Use Python's standard library, Python 3.11 or newer. Do not claim this tool is a security sandbox or proof of full task correctness.
